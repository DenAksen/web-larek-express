## Команды для запуска проекта

### Установка всех зависимостей
`npm run install:all`
Устанавливает зависимости для корневого проекта, бэкенда и фронтенда.

### Режим разработки (одновременный запуск бэкенда и фронтенда)
`npm run dev`
Запускает бэкенд и фронтенд в режиме разработки с горячей перезагрузкой.

### Сборка проекта
`npm run build`
Собирает production-версии бэкенда и фронтенда.

### Запуск production-версии
`npm run start`
Запускает собранные версии бэкенда и фронтенда.

## Отдельные команды

### Бэкенд
- `npm run dev:backend` — запуск бэкенда в режиме разработки
- `npm run build:backend` — сборка бэкенда
- `npm run start:backend` — запуск собранного бэкенда

### Фронтенд
- `npm run dev:frontend` — запуск фронтенда в режиме разработки
- `npm run build:frontend` — сборка фронтенда
- `npm run start:frontend` — запуск preview собранного фронтенда
